## Comparisons

| Priority | Operator     |        |
|----------|--------------|--------|
| 1        | +, -         | unary  |
| 2        | **           |        |
| 3        | *, /, //, %  |        |
| 4        | +, -         | binary |
| 5        | <, <=, >, >= |        |
| 6        | ==, !=       |        |

## Control structures
* any variable after `for` is called 'control variable'
* if we use a function, it `feeds` the loop, e.g. `range()`
* `pass` is an `empty instruction`

## more functions
* `range` can take 3 args, `start`, `stop`, `step`
  * `range` can go in asc or desc depending on step being positive/negative
